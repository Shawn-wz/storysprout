# 全量预训练的结果与判断

本次权重来自 models/run_20261118_183053_375283/best.pth。日志确认训练了 1 轮，累计 211,213 次更新、325,448,604 个有效目标 token，耗时约 71.3 分钟。步数与 token 数和准备的数据清单一致。best.pth 与 epoch_1.pth 的文件内容相同。

本轮执行了四个模型的验证、人物归属测试和统一提示续写，训练更新次数为 0。评估前后已核对权重指纹。逐项结果在 results.md，机器可读记录在 comparison.json 和 audit.json。

## 语言预测表现改善

|模型|原验证集 loss|清洗验证子集 loss|人物归属正确率|
|---|---:|---:|---:|
|50 万篇训练 1 轮，C 组|1.9994|1.8969|59.6%|
|10 万篇训练 5 轮|2.0325|1.9276|47.7%|
|此前用于 SFT 的预训练底座|1.8526|1.8359|54.2%|
|本次全量训练|1.8309|1.7317|53.4%|

全量模型在这四个模型中的验证 loss 最低。相对 C，原验证集 loss 下降约 8.42%，清洗验证子集下降约 8.71%。相对此前的预训练底座，两项分别下降约 1.17% 和 5.68%。

清洗验证子集包含原验证集中的 1,886 篇故事，过滤了疑似乱码及非法内容。全量训练在这部分数据上的改善更明显。

全量模型的累计训练 token 约为 C 的 3.38 倍。这个比较同时增加了数据覆盖面与训练计算，其收益包含两者影响。

## 人物归属测试没有显示稳定改善

沿用的 384 道题中，全量模型答对 205 道，C 答对 229 道。按交接事件之后的间隔拆分，结果如下。

|实际间隔 token|C 正确率|全量模型正确率|
|---|---:|---:|
|18|64.1%|57.0%|
|78|63.3%|50.8%|
|161|51.6%|52.3%|

额外移除环境描写后，间隔为 5 个 token，全量模型的正确率仍只有 54.7%。目前的薄弱点在很短的关系表述中就能出现。

进一步拆分 18-token 间隔下的句式，全量模型在 64 道 gave 题中只答对 13 道，在 64 道 got 题中答对 60 道，分别为 20.3% 与 93.8%。

gave 和 got 两类题的持有人分别是另一位人物和句子主语。这种结果与明显的句子主语偏好相符。下面四个实测前缀均加入相同的环境描写，再接 The key was now with。模型在两个候选人名之间都更偏好交接句的主语。

|交接句|正确持有人|模型更偏好的候选人名|
|---|---|---|
|Mia gave the key to Ben.|Ben|Mia|
|Ben gave the key to Mia.|Mia|Ben|
|Mia got the key from Ben.|Mia|Mia|
|Ben got the key from Mia.|Ben|Ben|

这里比较的是两个候选人名的下一 token 分数。对于每对姓名和每件物品，将姓名互换与 gave/got 交叉组合成四道题，在同一组全部答对能进一步抑制固定人名和主语偏好的影响。全量模型在 5-token 和 18-token 两组中，均为 0/32 组全部答对，完整拆分见 role_breakdown.json。

测试采用同一模板族，不同填充内容也会影响预测。结果需要与自由续写结合，不能直接据此给出模型记忆距离的上限。

## 自由续写中的实际错误

使用原有四个故事开头，分别生成 temperature 0.5、0.8、seed 2026 的续写，并额外生成 argmax 续写。每次预算均为 160 个新 token，所有模型使用相同条件。文本保存在 generations.md。

全量模型的 argmax 续写里仍出现以下情况。

- Alice 已经在路边发现了迷路的狗，后文却询问狗在哪里，随后变成狗带领狗寻找目标。
- 青蛙帮助兔子过河，后文写成青蛙感谢青蛙，并反复说青蛙帮助青蛙过河。
- Tom 和 Milo 原本在找灌木下的球，续写转向滑梯，反复描述爬台阶与滑梯。
- Lily 种下种子后，情节转向小鸟，并重复送礼物的句子。

这些观察说明当前模型已经可以形成顺畅的局部语言和常见故事段落，但人物、物品、目标与动作之间的关系仍不稳定。仅由四个提示词形成的定性观察，无法给出整体故事质量的精确分数。

## 对下一步优先级的影响

这次全量训练继续改善了语言预测，但人物追踪指标与自由续写没有显示同等幅度的改善。此前优先扩充数据的判断获得了语言建模指标的支持，而继续扩充相同类型语料对逻辑一致性的边际收益，当前证据仍有限。

后续分析应更关注角色状态追踪所需的训练信号、结构容量与训练充分程度。它们各自的贡献仍需要独立对照。当前结果无法单独确定某个结构部件是主要瓶颈。

本次只有最终轮的验证记录，缺少训练中的验证曲线。现有验证集与人物归属模板也已被反复用于实验比较，因此这些结果属于开发评估。checkpoint 没有保存独立的训练数据路径与指纹，本轮从步数、token 数和准备清单的一致性核对训练规模。
