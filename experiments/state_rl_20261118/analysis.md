# 专项 SFT 与可验证奖励 GRPO 的实验结论

本次以全量 TinyStories 预训练底座为共同起点，完成了专项 SFT、继续 SFT、GRPO，以及奖励饱和后的难题补充对照。

实验显示，专项 SFT 可以明显改善受控状态追踪。GRPO 在更难的分布外任务上有局部收益，但两轮实验都没有显示全面优于继续 SFT。普通故事续写也没有稳定改善。

## 第一轮控制与结果

程序生成了 8,192 道 SFT 训练题、512 道开发题及 4,096 道 RL 提示候选。题目覆盖物品持有者与物品位置，包含多个物品、独立干扰事件、交接与交换。答案由显式状态机重放事件得到。SFT 训练 6 轮，开发集最优权重为第 5 轮，正确率为 98.8%。

继续 SFT 和 GRPO 均从这一权重出发，使用完全相同的 1,600 个提示组、400 次更新和 12,800 个回答槽位。继续 SFT 对每个提示重复正确答案 8 次，GRPO 则全词表独立采样 8 个回答并用正确答案规则打分。

两个分支学习率均为 1e-5，Adam 默认参数，梯度范数上限为 1.0。GRPO 使用现有组内优势归一化与裁剪损失，KL 系数 0.02，clip epsilon 为 0.2，每组样本更新一次，最多生成 4 个 token。额外词语和插入角色标记的回答得分为 0。

|评估|专项 SFT|继续 SFT|GRPO|
|---|---:|---:|---:|
|第一轮保留测试集，1,120 题|859/1120，76.7%|871/1120，77.8%|872/1120，77.9%|
|原 384 道人物归属开发题|296/384，77.1%|292/384，76.0%|293/384，76.3%|
|原故事验证 loss|2.1328|2.1426|2.1315|

原始全量预训练底座在原人物归属开发题上为 205/384，53.4%，故事验证 loss 为 1.8309。由同一权重结构学到明显更高的关系判断正确率，说明这个规模的模型在受控状态追踪上仍有学习空间。

第一轮新题采用自由生成单个答案。原始底座尚未学习这套聊天问答格式，在该指标上只有 2/1120。base 到 SFT 的变化包含格式学习，因此判断关系能力迁移时需要同时参考原有的故事续写前缀下候选人名比较。

第一轮训练的平均奖励已达 98.7%，仅 2.2% 的回答组同时出现正确与错误答案，400 次更新中只有 34 次出现了这类组。这个阶段的任务奖励信号接近饱和，难以用它判断 RL 对困难状态追踪的作用。

## 追加难题实验

针对训练奖励饱和，保留第一轮全部结果后追加独立难题对照。难题设置为 3–5 次目标状态变化、独立物品干扰和约 90–130 token 的环境描写，保持输入不超过 244 token。长度约束使各难度的实际占比不同，详见 audit.json。

追加的两个分支都重新从同一个专项 SFT 权重出发。更新次数、提示组、回答槽位、学习率和 GRPO 参数与第一轮相同。新增测试集有 640 道题，两个分支完成固定的 400 次更新后才评估。

|新测试集|专项 SFT 起点|继续 SFT，难题|GRPO，难题|
|---|---:|---:|---:|
|同分布难题，320 题|206/320，64.4%|290/320，90.6%|274/320，85.6%|
|专项训练未见人名与句式，320 题|38/320，11.9%|77/320，24.1%|96/320，30.0%|
|两类合计，640 题|244/640，38.1%|367/640，57.3%|370/640，57.8%|

GRPO 在分布外难题上比继续 SFT 多答对 19 道，提升 5.94 个百分点；在同分布难题上少答对 16 道，下降 5 个百分点。合计只多答对 3 道。

在分布外难题中，人物持有者题的正确率仍很低。继续 SFT 为 3/160，GRPO 为 16/160。位置题分别为 74/160 与 80/160。RL 有局部迁移收益，但对新人名的复杂关系追踪仍未形成可靠能力。

按固定测试题进行配对自助法抽样，分布外正确率差的 95% 区间约为 +2.8 至 +9.1 个百分点，同分布为 -7.8 至 -2.5 个百分点，两类合计为 -1.7 至 +2.5 个百分点。这些区间只反映题目抽样变化，未覆盖训练随机性与多重比较影响。

追加难题的奖励差异组占比提高到 14.6%，400 次更新中有 184 次出现此类组，平均采样奖励从前 100 次的 0.698 升到后 100 次的 0.871。这轮结果体现了有效训练信号下的变化。

## 故事生成的代价

专项问答的改善未稳定迁移到自然故事创作。难题 SFT 和难题 GRPO 的故事验证 loss 分别为 2.1256 与 2.1359，均高于原底座的 1.8309。

在原有四个故事开头的贪心与采样续写中，仍能观察到角色替换、情节偏离和过早结束。Tom 与 Milo 找球的故事，专项训练后的贪心续写曾直接变为 “Tom and Max” 并结束。难题 GRPO 仍出现这一现象。

该变化与专项短答微调对普通语言建模的干扰相符。本轮未加入故事回放或混合语言模型损失，GRPO 的参考模型也是专项 SFT 权重，因此该 KL 约束不会直接恢复专项 SFT 之前的故事分布。

## 如何使用这次结论

专项训练信号在当前模型上有效，关系识别任务上的大部分收益来自 SFT。自动状态机已经提供了正确答案，直接监督训练在同分布任务上尤其高效。

GRPO 在更困难的组合泛化上显示了一定潜力。当前证据支持继续研究这类局部收益，但不支持把 RL 作为故事逻辑错误的通用修复方案。

面向故事生成，更需要同时关注故事保真、训练人名与句式覆盖，以及状态任务向自然叙事的迁移。任务问答的正确率和普通故事质量需要分别验收。

## 文件与复核

- results.md 为第一轮结果，hard_results.md 为追加难题与配对差异。
- generations.md 为第一轮的完整故事续写对照，hard_generations.json 为两个难题分支的贪心续写。
- protocol.json 和 hard_protocol.json 记录两轮任务、来源指纹、预算与测试策略。
- audit.json 验证了 19,168 个 prompt 跨集合均无重复、所有标签与事件重放一致，以及来源权重和最终权重的指纹。
- sft/best.pth 是开发集选出的专项 SFT 权重，其实际轮次为 5、更新数为 2,560。四个继续训练分支均保存了 400 次更新后的权重及 Adam 状态。

实验采用单个训练随机种子。原 384 题属于持续使用的开发测试，训练任务也接触了其中的人名和交接词。第一轮 1,120 道测试题在追加训练前已评估，追加分支对它们的复测属于探索性结果。新增 640 道难题在追加分支完成后统一评估。两个分支匹配提示与更新预算，GRPO 还需要额外的采样、旧策略和参考策略前向计算。
